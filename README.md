
# WhatNext Vision Motors
### Shaping the Future of Mobility with Innovation and Excellence

## About the Project
WhatNext Vision Motors is a Salesforce-based vehicle sales and order management project designed to streamline vehicle inventory, customer orders, and stock management.

The project uses Salesforce CRM capabilities to manage vehicle records, track available stock, process vehicle orders, and improve order-handling workflows.

## Key Features
- Vehicle inventory management
- Vehicle order management
- Stock availability tracking
- Order status management
- Automated vehicle stock updates
- Salesforce Apex classes and triggers
- Salesforce Flows for business process automation

## Technology Stack
- Salesforce CRM
- Salesforce Apex
- Apex Triggers
- Salesforce Flows
- Salesforce DX
- Visual Studio Code
- Salesforce CLI
- Git and GitHub

## Project Structure
- `force-app/main/default/` – Salesforce metadata, including Apex classes, triggers, flows, objects, and other components.
- `config/` – Project configuration files.
- `scripts/` – Scripts used for development tasks.
- `sfdx-project.json` – Salesforce DX project configuration.

## Setup Instructions
1. Install Salesforce CLI.
2. Install Visual Studio Code and the Salesforce Extension Pack.
3. Clone this repository.
4. Open the project folder in Visual Studio Code.
5. Authorize your Salesforce Developer Org.
6. Retrieve or deploy the required Salesforce metadata.
7. Test the project features in your Salesforce org.
